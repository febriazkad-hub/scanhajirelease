# ScanHaji

Aplikasi portable untuk scan paspor dan impor data jemaah SISKOHAT.

Repo distribusi resmi: https://github.com/febriazkad-hub/scanhajirelease

**Status: rilis pertama belum diterbitkan.** Tautan unduhan tersedia setelah paket selesai diuji dan dipublikasikan.

Unduh **ScanHaji-win-Portable.zip** dari rilis stabil terbaru, ekstrak seluruh isinya ke folder yang dapat ditulis, lalu jalankan **ScanHaji.exe**. Windows memerlukan .NET Framework 4.8.

Setelah paket pertama dipasang, aplikasi mengecek rilis stabil secara otomatis. Pembaruan diunduh di latar belakang dan dipasang setelah aplikasi ditutup. Data dan pengaturan tetap berada di akar folder portable. Untuk memindahkan ke PC lain, salin seluruh folder beserta Data/settings.

Repo ini hanya untuk rilis aplikasi. Jangan unggah data jemaah, hasil scan, konfigurasi pengguna atau API key.
