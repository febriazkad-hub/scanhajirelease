# ScanHaji

Aplikasi portable untuk scan paspor dan impor data jemaah SISKOHAT.

Unduh **[ScanHaji-win-Portable.zip](https://github.com/febriazkad-hub/scanhajirelease/releases/latest/download/ScanHaji-win-Portable.zip)** dari rilis stabil terbaru. Ekstrak seluruh isinya ke folder yang dapat ditulis, lalu jalankan **ScanHaji.exe**. Versi 2.3.0 membawa runtime .NET sendiri untuk Windows 10/11 x86/x64; pengguna tidak perlu memasang .NET, Excel/Office atau DLL tambahan. Impor XLS/XLSX dapat dipakai tanpa internet.

Setelah paket pertama dipasang, aplikasi mengecek rilis stabil bernomor lebih tinggi secara otomatis. Pembaruan diunduh di latar belakang dan dipasang setelah aplikasi ditutup. Data/pengaturan tetap di akar folder portable. Untuk pindah PC, tutup aplikasi dan salin seluruh folder beserta Data/settings.

Baca [panduan pengujian](TEST-PORTABLE.md), juga tersedia di `current/TEST-PORTABLE.md` dalam paket. Uji impor, tutup/buka kembali, pindah folder/PC dan auto-update. Windows Application Control tetap dapat mensyaratkan aplikasi dari penerbit tepercaya.

Repo ini hanya untuk rilis aplikasi. Jangan unggah data jemaah, hasil scan, konfigurasi pengguna atau API key.
